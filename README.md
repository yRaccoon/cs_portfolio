#  My Portfolio Website

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_Here-4ade80?style=for-the-badge&logo=github&logoColor=white)](https://yraccoon.github.io/cs_portfolio/)
[![GitHub Pages](https://img.shields.io/badge/Hosted_on-GitHub_Pages-black?style=for-the-badge&logo=github)](https://pages.github.com/)

A warm, coffee-shop-themed responsive portfolio website for a Computer Engineering graduate and software developer.
## 🚀 Built With
- **HTML** – structure and content  
- **CSS** – custom styling (coffee palette)  
- **JavaScript** – interactivity and animations  
- **Tailwind CSS** – modern, responsive UI design  
- **Font Awesome** – Icon library
- **Formspree** – Contact form handling

## ✨ Features
- Warm coffee-shop theme (roast / espresso / latte / cream palette)
- Playfair Display (headings) + Inter (body) + Caveat (handwritten accents) typography
- Latte-art hero with typewriter effect
- Skill bars that animate on scroll
- Project filtering by category; Details buttons link to GitHub repos
- Journey timeline, contact form with toast feedback
- Responsive layout with mobile navigation drawer

## 🙏 Credits
- Icons: Font Awesome
- Fonts: Google Fonts (Playfair Display, Inter, Caveat)
- CSS Framework: Tailwind CSS
