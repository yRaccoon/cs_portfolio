#  My Portfolio Website

[![Live Demo](https://img.shields.io/badge/Live_Demo-View_Here-4ade80?style=for-the-badge&logo=github&logoColor=white)](https://yraccoon.github.io/cs_portfolio/)
[![GitHub Pages](https://img.shields.io/badge/Hosted_on-GitHub_Pages-black?style=for-the-badge&logo=github)](https://pages.github.com/)

A warm, coffee-shop-themed portfolio website for a Computer Engineering graduate and software
developer — rebuilt as a modern React single-page application.

## 🚀 Tech Stack

- **React 19** – component-based UI and interactivity
- **Vite** – fast development server and optimized production builds
- **Tailwind CSS v4** – utility-first styling with a custom coffee palette (`@theme` tokens)
- **Font Awesome 6** – icon library (via `@fortawesome/react-fontawesome`)
- **Formspree** – contact form handling (AJAX + toast feedback)


## 📁 Project Structure

```
cs_portfolio/
├── index.html              # Vite entry (fonts + favicon)
├── public/
│   └── assets/             # Static images & resume PDF
├── src/
│   ├── components/         # Navbar, Hero, About, Skills, Projects, Journey, Contact, Footer
│   ├── data/               # projects.js, skills.js, journey.js
│   ├── hooks/              # useTypewriter, useActiveSection, useScrollReveal
│   ├── utils/              # asset() path helper
│   ├── App.jsx             # Section composition
│   ├── main.jsx            # React entry point
│   └── index.css           # Tailwind v4 theme tokens + custom styles
```
